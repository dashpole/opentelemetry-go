# Experimental Log Features

[![PkgGoDev](https://pkg.go.dev/badge/go.opentelemetry.io/otel/log/x)](https://pkg.go.dev/go.opentelemetry.io/otel/log/x)

This package contains experimental options and extension interfaces for the OpenTelemetry log package.
These features are currently under development and not part of the stable API.
They may be changed in backwards-incompatible ways, or removed entirely.
